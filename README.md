## 🌟 ฟังก์ชันการทำงานหลัก

1. **สแกนและจำแนกอาหารไทย (Thai Food Recognition):**
   - อัปโหลดรูปภาพอาหารไทย หรือกดเลือกเมนูทดสอบทันใจ (ต้มยำกุ้ง, ผัดกะเพราไข่ดาว, ผัดไทย, ส้มตำไทย, ข้าวมันไก่, แกงเขียวหวาน)
   - AI ตรวจจับชื่อเมนูทั้งภาษาไทยและอังกฤษ พร้อมแสดงเปอร์เซ็นต์ความมั่นใจ (Confidence Score)

2. **ประเมินแคลอรี่และสารอาหารหลัก (Macro Nutrients):**
   - พลังงานรวม (Calories - kcal)
   - โปรตีน (Protein - g)
   - คาร์โบไฮเดรต (Carbohydrates - g)
   - ไขมัน (Fat - g) และปริมาณโซเดียม (Sodium)

3. **ข้อมูลเชิงลึกด้านสุขภาพ:**
   - 🌿 **วัตถุดิบและสมุนไพรเด่น:** บอกส่วนประกอบสมุนไพรไทย เช่น ข่า, ตะไคร้, ใบกะเพรา
   - ⚠️ **สารก่อภูมิแพ้ (Allergens):** แจ้งเตือนสารที่อาจแพ้ เช่น กุ้ง, ถั่วลิสง, ไข่
   - 💡 **คำแนะนำเพื่อสุขภาพ (Health Tips):** วิธีรับประทานเพื่อสุขภาพ เช่น การลดโซเดียม การเลือกเนื้อสัตว์

4. **ระบบอ่านออกเสียง (Voice Assistant):**
   - กดปุ่ม **"🔊 ฟังคำอธิบาย"** เพื่อให้ระบบอ่านชื่อเมนู แคลอรี่ และคำแนะนำเป็นเสียงพูดภาษาไทย

## 💻 ตัวอย่างโค้ด AI for Thai ที่ใช้ในโปรเจกต์ (สำหรับใส่สไลด์/รายงาน)

```python
from aift import setting
from aift.image import thaifood

# 1. กำหนด API Key ที่ได้จาก aiforthai.in.th
setting.set_api_key('YOUR_AIFORTHAI_API_KEY')

# 2. เรียกวิเคราะห์ภาพอาหารไทย
result = thaifood.analyze('tomyum.jpg')
print("เมนูอาหารที่ตรวจพบ:", result)
```
